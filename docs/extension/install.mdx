The memory404 Chrome extension lets you save tabs from any page with one click.

## Download (recommended for new users)

1. Download [`memory404-extension.zip`](/downloads/memory404-extension.zip) from the app (Settings → Chrome extension, or the empty vault CTA).
2. Unzip it — you should see `manifest.json` at the top level.
3. Follow **Load in Chrome** below and select that unzipped folder.
4. Set **App URL** to the memory404 origin you use (this hosted app, `http://localhost:3000`, or **your own self-hosted deployment**).

You can also open **Settings → Chrome extension** in the web app for a copyable App URL for the current site.

## Build from source

```bash
cd extension
npm install
npm run build
```

The built extension is in `extension/dist/`. The same build also writes `public/downloads/memory404-extension.zip` for the in-app download.

## Load in Chrome

<Steps>
  <Step title="Open extensions">
    Navigate to `chrome://extensions/` in Chrome.
  </Step>
  <Step title="Enable developer mode">
    Toggle **Developer mode** in the top-right corner.
  </Step>
  <Step title="Load unpacked">
    Click **Load unpacked** and select the unzipped download folder (or `extension/dist` if you built from source).
  </Step>
  <Step title="Configure App URL">
    Open the extension popup, go to Settings, and set the App URL to your server:
    - This site / production: your memory404 origin (e.g. `https://memory404.vercel.app`)
    - Local: `http://localhost:3000`
    - Self-hosted: the origin where you deployed memory404
  </Step>
</Steps>

## Extension details

| Property | Value |
|----------|-------|
| Manifest version | 3 |
| Name | memory404 |
| Version | 0.1.0 |
| Default shortcut | `Alt+Shift+L` / `Option+Shift+L` |
| Omnibox keyword | `lk` |

## Permissions

| Permission | Purpose |
|------------|---------|
| `tabs` | Read active tab URL and title |
| `activeTab` | Access current tab content |
| `tabGroups` | Save entire Chrome tab groups |
| `scripting` | Extract Open Graph metadata from pages |
| `storage` | Cache groups and last-saved group ID |
| `omnibox` | Quick-save from address bar |
| `contextMenus` | Right-click save options (including links) |

To save a specific link on a page, right-click it and use **Add to LK** (see [Context menus](/docs/extension/context-menus)).

## Host permissions

The extension can communicate with:

- `localhost:3000` (local dev)
- `memory404.vercel.app` (production)
- `*.vercel.app` and `*.onrender.com` (deployed environments)
- All `http(s)://` URLs (for metadata extraction)

## Verify installation

1. Click the memory404 icon in the toolbar
2. The popup should load your groups from the API
3. Save the current tab to confirm the connection

<Tip>
If groups fail to load, check that the App URL in extension settings matches your running server and that CORS allows `chrome-extension://` origins.
</Tip>
