On any webpage, hover a link for a moment and a **Remember this link** chip appears.

## How it works

1. Hover an `http`/`https` link for ~400ms
2. Click **Remember this link**
3. The extension popup opens with that URL ready — pick a group and save

If the popup cannot open (restricted page), the link is saved with your last-used group instead.

## Tips

- The chip uses a shadow DOM so page styles do not affect it
- Same-page hash links are ignored
- Press `Escape` or scroll to dismiss the chip
